Privacy Policy

Anime CD Liquidation Sale App  ·  Effective May 2026

Overview

This application is a private, single-user tool used solely by its developer to manage photo albums on the Anime CD Liquidation Sale Facebook Page. It is not distributed to or used by any third parties.

Data Collection

This application does not collect, store, or transmit any personal data from any user. No analytics, tracking, or logging of user information takes place.

Facebook Data

The application accesses the Anime CD Liquidation Sale Facebook Page via the Meta Graph API using a Page access token belonging to the page administrator. Access is limited to managing photos within that page's albums. No data from Facebook users other than the page administrator is accessed or retained.

Third-Party Sharing

No data of any kind is shared with third parties.
